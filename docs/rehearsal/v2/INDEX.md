- 환경: AVD `Pleos_Connect_v2.1.0`(2560x1440, `-no-snapshot`), 앱 `app-debug.apk`(최신 엔진·UI + 이번에 추가한 정 주임 시드), 게이트웨이 = 실제 SDK.
- 빌드: `./gradlew :app:assembleDebug :app:testDebugUnitTest` 통과(정 주임 시드 추가 전·후 모두).
- 캡처: `adb exec-out screencap -p`. 총 **49장**.
- VC 계기판: 시작 시 31,352km(이전 워커가 올려 둔 값). 각 페르소나는 데모 패널 적용 시 VC 값으로 자동 동기화돼 **시작 계기판이 옮겨짐**(사용·목표·비용 숫자는 시드 그대로). 이상값 테스트 후 VC는 31,932km.
- 페르소나 전환 순서: 김 대리 → (기어 D/P, +580) → 이 과장 90일 → 이 과장 499일 → 박 과장 → 정 주임 → 반쪽 창(정 주임, 김 대리).
- 주행 중 잠금·이상값 보류는 화면 구조가 페르소나와 무관해 **김 대리로만** 캡처했다. 반쪽 창은 정 주임(홈·이번 주·출구, 보험은 점진 질문 시트에 막혀 미캡처)과 김 대리(홈·이번 주)만.
- 정 주임은 데모 메뉴에 없어서 `demo/PersonaSeeds.kt`에 `PersonaId.JUNG` 시드를 추가했다(FEATURE_GUIDE 저주행 픽스처: 김 대리와 같은 계약, 2028-03-16, 누적 12,000km, 지난주 주말 100+100km, 이번 주 월~목 25km).

## 캡처 방법 메모
- VC HTTP: `adb forward tcp:8088 tcp:8088` + `POST /browser/session?client=...` 1초 하트비트, `PUT /vehicle/gear?gear=Drive|Park`, `PUT /vehicle/odometer?traveled_distance_km=31932`.
- 한글 입력(강릉)은 `adb input text`가 안 되어 화면 한글 키보드 좌표를 눌러 입력.
- 반쪽 창: 앱 오른쪽 가장자리 핸들(⋮)을 왼쪽으로 끌면 내비와 나란히 표시됨. 이 상태에선 `uiautomator dump`가 내비 창만 반환하므로 좌표로 조작.

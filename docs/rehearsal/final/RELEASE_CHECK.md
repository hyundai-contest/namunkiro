## 4. 1차(R8 최적화 켬, 20:51 빌드) 실패 기록

- 증상: 실행할 때마다 `FATAL EXCEPTION: main`.
  - `Unable to get provider androidx.startup.InitializationProvider`
  - `java.lang.IllegalAccessError: Class kotlin.collections.h extended by class wp is inaccessible`
- 원인(mapping 대조): `CollectionsKt__IterablesKt -> kotlin.collections.h`는 패키지 전용 클래스이고 패키지가 그대로 유지됐다. 이를 상속하는 `CollectionsKt__MutableCollectionsJVMKt`만 `wp`로 바뀌어 기본 패키지로 옮겨졌다. `optimization { packageScope = androidx/kotlin/kotlinx }`와 `-allowaccessmodification`이 함께 쓰인 탓으로 보인다.
- 조치: 조정자가 release 최적화를 끔(`optimization.enable=false`). 2차 빌드에서 해소를 확인했다.
- 교훈: R8 관련 문제는 단위 테스트·debug 빌드로 잡히지 않는다. release는 **설치 후 실행**까지 확인한다.

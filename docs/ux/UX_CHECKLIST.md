# UI 변경 검토 체크리스트 (UX 게이트)

UI가 바뀌면 UX 담당 에이전트가 이 목록으로 검토하고 결과를 `docs/ux/reviews/YYYYMMDD-HHMM-<주제>.md`에 남긴다.

1. 핵심 가치: 화면에서 km → 원 인과가 시각적으로 보이는가
2. 3초 판독: 주 시각 요소 1개 + 큰 금액 1개인가, 카드당 문장 1줄 이하인가
3. 개념 노출: 내부 계산 용어(예산·이월·분할 등)가 화면에 없는가
4. 상태 톤: 초과 / 회복 어려움 / 덜 탐 상태가 올바르게 구분되는가
5. 정직성: 미확인을 0으로 표시하지 않는가, 모의 값 표시가 있는가
6. 차량 맥락: 주행 중 잠금, 76dp, 24sp, 반쪽 창
7. 숫자 일관성: 엔진 값·명세(신청서 최신본)·FEATURE_GUIDE와 일치하는가
8. 회귀: 이전 리뷰에서 해결된 항목이 다시 나빠지지 않았는가
9. 시각화 정직성: 그림이 실제 데이터인가, 라벨이 그림 위에 있는가, 범례 1줄 이하인가, 색 외 구분이 있는가
10. 숫자 신뢰: 옆 숫자로 검산되는가, 점추정이 범위 안인가, 목표를 지키면 약속한 결과가 참인가, 시드가 결론을 바꾸지 않는가
11. 피드백: 선택 상태가 즉시 보이는가, 바뀐 숫자가 같은 시야에서 갱신되는가
12. 증거: 최신 빌드 캡처로 검토했는가(아니면 '재확인 필요' 표기)
13. 인터랙션 (`UX_PRINCIPLES.md` §5-1)
    - 13a 목적: 모든 움직임이 값 변화를 보여 주는가(장식 없음), km→원 인과 순서(km 먼저, 원 나중)인가
    - 13b 안전: 주행 중(기어≠P·UX 제한) 애니메이션 0인가, reduce-motion 설정에서 즉시 최종값인가, 모션 없이도 정보가 완전한가
    - 13c 타이밍: 값 전환 250~350ms·ease-out인가, 600ms 초과나 연쇄 연출이 없는가, 동시에 움직이는 요소가 1개(1체인)인가
    - 13d 직접 조작: 문장 설명 대신 슬라이더·드래그·스크럽이 있는가, 핸들 76dp 이상·단위 스냅·미리보기와 저장 구분이 있는가
    - 13e 말풍선: 탭하면 값+근거 말풍선 1개가 뜨는가, 닫힘 규칙이 일관되는가, 탭 가능함이 보이는가
    - 13f 복원·되돌리기: 잠금→정차, 탭 이동, 창 크기 변경, 재시작 후 위치·선택·말풍선이 복원되는가, 조작 후 되돌리기와 이전 대비 차이가 보이는가

세부 기준은 `UX_PRINCIPLES.md` §0~§7.

판정: 통과 / 조건부 통과(P1 목록) / 반려(P0 목록). 점수(10점)와 이전 대비 변화도 적는다.
